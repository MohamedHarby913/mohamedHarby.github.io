Wireshark for Beginners: Capture Packets

I installed and set up Wireshark on my Ubuntu machine to analyze network traffic for cybersecurity practice. After configuring the tool, I applied display filters to detect HTTP and HTTPS packets, allowing me to observe and analyze web traffic in real time. I also used display filters to capture packets containing specific IP addresses, which helped me identify the origin and destination of network communications. This hands-on experience enhanced my understanding of network protocols and improved my packet analysis skills, reinforcing key concepts essential for cybersecurity tasks.
